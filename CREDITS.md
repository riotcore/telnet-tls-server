## Dependencies

This project uses established libraries rather than implementing cryptography
itself:

- **OpenSSL** for TLS.
- **libsodium** for Argon2id password hashing and secure memory helpers.
- **libssh** for the SSH protocol, key exchange, encryption, authentication
  messages, and channels.

Those projects retain their own authorship, copyrights, trademarks, and license
terms. Linking to them does not make their source code part of this repository.

## Standards and community input

Telnet RFCs, MUD protocol specifications, client documentation, interoperability
testing, bug reports, and technical discussion all help shape this project's
behavior.

Bug reports, review, and suggestions are welcome. Code contributors should be
credited for the work they contribute.
